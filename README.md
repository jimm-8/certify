## About the System

CERTIFY is a web-based automated certification management system developed for Batangas State University – Alangilan Campus. The system automates the generation of academic certifications requested by students, reducing manual workload and improving efficiency in the registrar’s office.

---

## Purpose

The system aims to:

- Reduce manual certificate preparation
- Minimize human errors
- Speed up certification request processing
- Provide secure and organized management of certification records

---

## Main Features

- Automated certificate generation  
- Certification request status monitoring  
- Secure authentication for authorized users  
- QR code verification for certificate authenticity  
- Centralized certification data management

## Backend Framework

### FastAPI

The backend of CERTIFY is built using **FastAPI**, a modern Python web framework designed for building high-performance APIs.

FastAPI is used in this system to:

- Handle API requests from the frontend
- Manage authentication and authorization
- Process certificate generation requests
- Retrieve and store data in the database
- Provide secure and structured endpoints for system operations

FastAPI was selected because of its:

- High performance comparable to NodeJS and Go
- Automatic interactive API documentation
- Strong support for asynchronous operations
- Easy integration with modern Python libraries

To run the CERTIFY system locally, the following software is required.

- **Uvicorn** (ASGI server)
- **PostgreSQL 14+**

### Frontend Requirements

- **Node.js 18+**

- **Tailwind CSS**

- **Git**
- **GitHub**

## Database

The system uses **PostgreSQL** as the relational database management system.

PostgreSQL stores:

- Student certification requests
- Generated certificate records
- User authentication data
- System logs and transaction records
